뉴로모픽 컴퓨팅 시뮬레이션 프로젝트 요구 사항 명세서
작성자: 일산대진고등학교 2학년 학생
주제: Python 기반 SNN(Spiking Neural Network) 시뮬레이터 개발


1. 개요
1.1 시스템의 개요
본 시스템은 인간 뇌의 신경 구조를 모방한 뉴로모픽 컴퓨팅(Neuromorphic Computing)의 기본 원리를 Python 프로그래밍 언어를 통해 구현하는 시뮬레이션 프로그램입니다. 기존 폰 노이만 구조의 한계를 넘어서는 SNN(Spiking Neural Network) 모델을 설계하고, 이를 통해 저전력 고효율 연산의 가능성을 탐구합니다.
1.2 목표
* 생물학적 뉴런의 동작 원리(LIF 모델)를 코드로 구현하여 학술적 이해도 제고
* 시냅스 가중치 변화 알고리즘(STDP)을 통한 기계 학습 과정의 시각화
* 인공지능 및 뇌 과학 융합 분야에 대한 자기주도적 탐구 역량 증명 (생기부 기재 목적)


2. 기능적 목표
2.1 자료 흐름도(Data Flow)
입력 데이터가 스파이크로 인코딩되어 뉴런망을 통과하고 결과가 출력되는 과정은 다음과 같습니다.
단계
	주요 프로세스
	상세 설명
 
	1. 입력
	Spike Encoding
	데이터를 시계열상의 전기적 신호(Spike) 형태로 변환
	2. 처리
	LIF Neuron Model
	Leaky Integrate-and-Fire 수식을 이용한 막전위 연산
	3. 학습
	STDP Algorithm
	뉴런 간 신호 전달 타이밍에 따른 가중치(Weight) 업데이트
	4. 출력
	Data Visualization
	뉴런별 활성화 차트 및 전위 변화 그래프 출력
	2.2 소단위 명세서
* 뉴런 모듈 (Neuron.py): 막전위 변수 관리, 임계값 판정 로직, 불응기 처리 기능.
* 시냅스 모듈 (Synapse.py): 뉴런 간 연결 정보 저장, STDP 기반 가중치 변화량 계산.
* 메인 엔진 (Simulator.py): 전체 시간 흐름(Time-step) 제어 및 데이터 로깅.


3. 기타 요구 및 제약사항
3.1 성능 및 하드웨어 요구 사항
구분
	내용
	성능(Performance)
	NumPy 라이브러리를 활용하여 대량의 뉴런 연산을 병렬화하고 지연 시간 최소화
	하드웨어(Hardware)
	Python 3.10 이상 설치된 일반 PC 환경
	3.2 사용자 인터페이스(UI)
* 입력 양식: 시뮬레이션 파라미터(뉴런 개수, 학습률 등)를 상수로 입력.
* 출력 양식: Matplotlib를 사용한 Raster Plot 및 막전위 변화 시각화 결과물 제공.


4. 인수 조건 및 기대 효과
4.1 기능 시험 조건
1. 입력 자극에 대해 뉴런이 설정된 임계값에서 정확히 스파이크를 발생시키는가?
2. 시냅스 전후 뉴런의 스파이크 간격에 따라 가중치가 정상적으로 증감하는가?
4.2 탐구 및 발전 방향 (생기부 기재 포인트)
본 프로젝트를 통해 기존의 연산 방식과 생물학적 연산 방식의 차이를 정량적으로 분석하고, 미래 인공지능 하드웨어의 발전 방향에 대한 견해를 정리함. 특히 '에너지 효율성' 측면에서의 강점을 시뮬레이션 결과와 결합하여 고찰함.
